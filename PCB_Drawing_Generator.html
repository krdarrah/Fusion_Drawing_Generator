PDFs are written directly by this page as vector pages at the exact sheet size (Letter = 11 × 8.5 in), so no print dialog, margins or scaling are involved.
Everything (title block, spec, notes, logo, vendor image, hand-placed labels and added notes) is remembered per board name in this browser and can be saved to a .json. To rev a board: load the new .brd, then load the old .json (or the other way round); the notes come along.
If you print instead: paper size Letter, landscape, margins none, scale 100%, headers and footers off.
